# 声之形 · Shape of Sound

一座关于「克拉尼图形」（Chladni Patterns）的线上夜间科学艺术馆：声音驱动共振板振动，细沙沿波节线聚集，描绘出看得见的声音几何。

全馆按漫步动线编排为序厅与四大展厅，并配右侧科普手册抽屉：
- **序厅（HALL 00）**：全屏呼吸声纹沙盘与导览入口
- **声形画廊（HALL 01）**：8 件声学史与乐器采样试听、实时沙盘拨动与一键带入工坊调校
- **寻声猜形（HALL 02）**：7 道盲听辨纹挑战、错选声纹直观对比与持久化声学图鉴
- **声绘工坊（HALL 03）**：对数调频共振锁定、音色与共鸣和弦、麦克风实时/短句/长声年轮与多重曝光、四种盘形 × 四种色泽 × 四种显影材质、拍立得典藏卡导出与展厅发布
- **艺术展厅（HALL 04）**：云端公共展厅与本机「我的展厅」，支持粒子原貌有声重放与一键二创
- **声形之理**：5 章驻波科普图谱抽屉与「学霸模式」声学公式注释
